This is a discord bot for torn.com coded in python. it allows you to !track a flying user and it will ping you just before that user arrives back in torn.

As this bot was created for personal use, it will require some effort and knowledge of python to use it in your own private discord.
You will need to create your own discord application in order to get a bot token, this can be done through the discord developer portal with relative ease. The token you get from this application can be placed at the bottom of the main file.
The bot can run either locally or hosted on a service of your choice.
